# Security Policy

## Supported versions

Security fixes are provided for the production website at [https://visionforgestudio.app](https://visionforgestudio.app), which is built from the current `main` branch of this repository.

This is a public marketing site. It does not have user accounts.

## Reporting a vulnerability

Email [support@visionforgestudio.app](mailto:support@visionforgestudio.app) with:

- a description of the issue
- the affected URL or component
- steps to reproduce

Do not open a public GitHub issue for an unfixed vulnerability. Do not disclose the issue publicly, including in pull requests, social media, or exploit write-ups, before it has been remediated.

There is no paid bug-bounty program. Valid reports will be acknowledged, and a fix will be prepared for the production site.
